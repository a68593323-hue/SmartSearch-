# AKTU CSE SmartSearch

Search any AKTU B.Tech CSE subject by name, short form, code, semester or topic. Difficulty insights, syllabus topics, notes, PYQs and video lectures for Semesters 1-8.

Single-file static site: `index.html`.

## Deploy with GitHub Pages
1. Upload `index.html`, `logo.svg`, `README.md` to a new **public** repository.
2. Settings > Pages > Source: **Deploy from a branch** > `main` / `(root)` > Save.
3. Your site goes live at `https://<username>.github.io/<repo>/`.
